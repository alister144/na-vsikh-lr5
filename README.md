# НА ВСІХ / NA VSIKH

Навчальний статичний сайт доставки суші в Києві. Кузьміч Олексій, 4-16 ФТБ.

## Запуск

Розпакуйте архів і відкрийте термінал у папці `na-vsikh`. Потрібен Node.js 22 або новіший. Сторінки вже зібрані, залежностей для встановлення немає.

```sh
npm run dev
```

Відкрийте [http://127.0.0.1:4173/](http://127.0.0.1:4173/). У Windows можна двічі натиснути `Start-Windows.cmd`. Якщо порт зайнятий, запустіть `npm run dev -- 4180` і відкрийте [http://127.0.0.1:4180/](http://127.0.0.1:4180/).

## Перегляд

- Головна українською — `/uk/`. Повна англійська версія — `/en/`.
- Підбір на трьох із трьома умовами — `/uk/menu/?category=sets&people=3&portion=dinner&baked=1&spicy=no&rawfish=no`.
- Демо-адмінка — `/uk/admin/` або посилання в підвалі. Там можна додати, змінити й видалити страву, завантажити фото та відновити каталог.
- Кошик і демо-адмінка використовують локальне сховище поточного браузера. Сайт демонструє підбір і розрахунок, замовлення та оплати недоступні.

## Вихідні файли й збірка

`src/build.mjs` генерує HTML для обох мов. `assets/catalog.mjs` містить базовий каталог, правила підбору та кошика. `assets/words.mjs` містить локалізацію. Вихідні файли зберігаються поруч із готовими сторінками. Фотографії локальні. Походження й промпти збережені в `IMAGE-PROMPTS.md`, ліцензія Inter — в `assets/Inter-OFL.txt`.

Після змін згенеруйте сторінки через `npm run build`. Без SITE_URL локальна збірка не додає публічних URL у соціальні метадані. Для майбутньої публікації корінь репозиторію буде джерелом GitHub Pages (`main / (root)`). Перед публікацією задайте `SITE_URL` із фактичною адресою проєкту, тоді збірка створить абсолютні адреси сторінок та зображень у canonical, Open Graph і Twitter Card. У PowerShell — `$env:SITE_URL = 'https://<account>.github.io/<repository>'; npm run build`. У Bash — `SITE_URL='https://<account>.github.io/<repository>' npm run build`.

## Матеріали для ЛР №6

Використовується цей самий сайт зі сталими посиланнями на страви, підбір і доставку. Пізніше кожен із профілів Instagram, Facebook і Telegram матиме активне посилання, повне ПІБ і групу 4-16 ФТБ. Для кожного передбачено 3–5 публікацій з окремими текстами та візуалами. У `IMAGE-PROMPTS.md` збережено фактично використані промпти, результатами є фотографії в `assets/`.

## Виправлення й перевірка

- «Лише рослинний склад» діє як обов’язкова умова в меню та підборі. Страви перевіряються за інгредієнтами, сети — за всіма ролами. Старі посилання з `pref=plant` переходять на `plant=1`.
- У межах 15% від орієнтира підбір зіставляє вагу, ціну, різні роли, готові сети й необов’язковий бажаний смак. Однаковий склад з’являється один раз. За межами цього діапазону діє резервний підбір до 30% із тими самими обов’язковими умовами.
- Зміни каталогу оновлюють відкриті вкладки. Незбережені поля форми залишаються на місці. Конфлікт редагування тієї самої страви зупиняє збереження та залишає чернетку у формі.
- `npm test` перевіряє 240 комбінацій порцій і суворих фільтрів, підсумки страв і кошика, резервні результати та приклад «Запечений дует». У Chrome перевірено прямі посилання з параметрами в тестовому підкаталозі, обидві мови, адаптивність і застосування змін між вкладками. Публічна адреса GitHub Pages налаштовується після схвалення.
